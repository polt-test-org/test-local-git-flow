# Collection Email Agent

An AI agent that drafts personalized collection emails based on S/4HANA dunning data and outstanding invoices

## Overview

Uses A2A Protocol, LangGraph, LiteLLM, and SAP Cloud SDK.

## Structure

- `app/main.py` - A2A server entry
- `app/agent_executor.py` - Request handling
- `app/agent.py` - Agent logic
